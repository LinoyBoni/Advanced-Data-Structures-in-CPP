# Data Structures in C++ – Advanced Academic Coursework

This repository contains a collection of assignments completed as part of an advanced Data Structures course in C++. The course focuses on the design, implementation, and analysis of fundamental and advanced data structures, with an emphasis on efficiency, memory management, and algorithmic thinking.

All assignments were completed with full grades (100), reflecting strong understanding and practical implementation skills.

## 📚 Topics Covered

The coursework includes implementation and analysis of the following data structures and concepts:

- Disjoint Set Union (Union-Find / Foreign Sets)
- Hash Tables (Open addressing and chaining techniques)
- Trie Trees (Prefix Trees for efficient string processing)
- B-Trees and balanced tree structures
- Efficient search, insertion, and deletion algorithms
- Complexity analysis of operations (time and space)

## 🧠 Learning Objectives

The main objectives of this course were:

- Understanding advanced non-linear data structures
- Designing efficient solutions for large-scale data operations
- Analyzing algorithmic complexity (Big-O notation)
- Implementing memory-efficient and scalable structures in C++
- Strengthening problem-solving and algorithmic reasoning skills

## 🛠 Technologies Used

- C++
- Object-Oriented Programming principles
- Manual memory management
- Algorithmic design and analysis
